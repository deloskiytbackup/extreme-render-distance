# Extreme Render Distance 🔭

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Minecraft](https://img.shields.io/badge/Minecraft-1.21%20%7C%201.21.1-brightgreen.svg)]()
[![Fabric](https://img.shields.io/badge/Loader-Fabric-blue.svg)]()

**Extreme Render Distance** is a lightweight Fabric mod that uncaps the vanilla and Sodium render distance slider from 32 chunks up to **128 chunks** (over 2 kilometers of full-block visibility!).

---

## ✨ Features

- **Sodium & Vanilla Support**: Seamlessly uncaps the render distance slider up to **128 chunks** in Sodium's video settings and Vanilla options.
- **Singleplayer Server Uncap**: Automatically raises the integrated server chunk generator limit from 32 to 128 chunks so chunks actually generate and tick around you.
- **Dynamic Compatibility**: Safely adapts whether Sodium is installed or not.
- **Modpack Friendly**: Compatible with **Iris**, **Distant Horizons**, **Sodium**, and **Lithium**.

---

## 🚀 Performance Tips

> [!WARNING]
> Rendering 64–128 full vanilla chunks requires substantial CPU and RAM resources. 
> - Start by testing **48 to 64 chunks**.
> - Combine with **Distant Horizons** for distances beyond 64 chunks to achieve the best performance and panoramic visual fidelity.

---

## 📥 Installation

1. Install **Fabric Loader** (0.15+) for Minecraft **1.21** or **1.21.1**.
2. Drop `ExtremeRenderDistance-1.0.0.jar` into your `.minecraft/mods` folder.
3. Open Minecraft, go to **Options -> Video Settings**, and slide the Render Distance slider up to **128 chunks**!
